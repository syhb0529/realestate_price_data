아파트 실거래 조회

GitHub Pages에 바로 올릴 수 있는 단일 HTML입니다. 국토교통부 아파트 매매 실거래가 OpenAPI의 서비스 URL, GET 방식, XML 응답, 필수 요청값 LAWD_CD / DEAL_YMD / serviceKey를 기준으로 구성했습니다.

조회 설정

현재 파일에는 사용자가 제공한 서비스키가 들어 있습니다. 그대로 GitHub public 저장소에 올리면 키가 공개됩니다. 배포 후에는 키 재발급 또는 프록시 서버 사용을 권장합니다.
기술문서 기준 serviceKey는 필수이며 URL Encode 값을 사용합니다.
GitHub Pages는 정적 사이트라서 브라우저 CORS 제한으로 직접 호출이 막힐 수 있습니다.
공개 프록시는 불안정할 수 있습니다. 안정적으로 운영하려면 Cloudflare Worker 같은 본인 프록시를 두는 편이 좋습니다.
조회는 기술문서의 Call Back URL getRTMSDataSvcAptTrade에 맞춰 진행합니다. 필수 파라미터는 법정동코드 앞 5자리 LAWD_CD, 계약년월 6자리 DEAL_YMD, 그리고 serviceKey입니다.
